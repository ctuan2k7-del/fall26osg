1. Công thức Hiệu suất CPU (CPU Utilization)

CPU Utilization = 1 - p^n

  • p: Tỉ lệ thời gian chờ I/O; n: Số tiến trình trong RAM = (Tổng RAM - RAM OS) / RAM 1 tiến trình.
  • Câu 4: n=6, p=82% → 70.2% (A) | Câu 14: RAM=4GB, OS=2GB, P=1GB → n=2, p=50% → 75% (A)
  • Câu 38: RAM=16GB, OS=2GB, P=512MB → n=28, p=70% → 95.71% (B) | Câu 118: RAM=8GB, OS=2GB, P=3GB → n=2, p=60% → 64% (A)

2. Công thức Phân trang (Paging) & FAT

  • Câu 12 & 205: Địa chỉ 16-bit, Page size = 4KB (2^12 → offset 12-bit) → Page number = 16 - 12 = 4 bits → 2^4 = 16 trang.
  • Câu 17: Địa chỉ 32-bit = 10-bit PT1 + 12-bit PT2 + 10-bit Offset → Page size = 2^10 = 1-KB page (B).
  • Câu 41: Địa chỉ 32-bit, Page size = 128KB (2^17) → Số mục bảng trang = 2^32 / 2^17 = 2^15 (A).
  • FAT-16: tối đa 2^16 = 65,536 blocks. Block 16KB → Max = 1 GB (Câu 11); Block 4KB → Max = 256 MB (Câu 25); Phân vùng 2GB với block 32KB → cần FAT-16 (Câu 43, 223).
  • FAT-32 (Windows 95): Block 16KB → Max partition size = 2 TB (Câu 24).

Đưa Web Lên GitHub Pages (Miễn phí 100%)

Bước 1: Tải file chuẩn tên index.html

GitHub Pages yêu cầu file trang chủ phải có tên là index.html. Nhấn nút dưới đây để tải ngay file đã đóng gói sẵn toàn bộ 397 câu hỏi:

Bước 2: Kéo thả lên GitHub (Không cần gõ lệnh, mất 60 giây)
  1. Truy cập github.com/new, đặt tên Repository (ví dụ: fall26osg), chọn Public rồi bấm Create repository.
  2. Tại màn hình vừa tạo, bấm vào dòng chữ xanh uploading an existing file.
  3. Kéo thả file index.html vừa tải ở Bước 1 vào khung, sau đó bấm nút xanh Commit changes ở dưới cùng.
  4. Trên thanh menu của repo, bấm vào Settings → chọn mục Pages ở cột bên trái → tại mục Branch, đổi từ None sang main rồi bấm Save.
  5. Đợi khoảng 30 giây rồi tải lại trang, bạn sẽ nhận được đường link web chính thức dạng: https://ctuan2k7-del.github.io/fall26osg/
Hoặc đẩy bằng lệnh Git trên máy tính: 
git init
git add index.html
git commit -m "Deploy OSG202 study web app"
git branch -M main
git remote add origin https://github.com/ctuan2k7-del/fall26osg.git
